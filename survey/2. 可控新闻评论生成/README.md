### 使用流程

1. 用户 上传txt文件/输入文本信息/随机示例
2. 设置预期评论信息（情感倾向、是否过滤敏感词、评论主体、文本长度以及多样性）
3. 用户点击开始分析
4. 得到分析结果

### 基本原理（from kimi：根据文档生成的）


1. **敏感词判定**：
   - 存在一个敏感词库，该库可能是通过合并多个开源的敏感词表来构建的。这个库中包含了被认为不适当或敏感的词汇，用于在文本分析时进行识别和过滤。

2. **交互与指令（Prompt）**：
   - 用户通过设置特定的参数（如情感倾向、评论主体、文本长度等）来与大模型交互。

3. **大模型处理**：
   - 大模型接收到用户的指令后，会根据这些指令来生成或处理文本。这涉及到几个关键技术：
     - **属性级别的安全可控文本生成技术**：确保生成的文本在情感、话题等属性上的可控性，避免生成不当内容。
     - **注意力交互**：通过注意力机制，模型能够关注用户指定的属性和文本内容，生成与用户指令相匹配的文本。
     - **属性判别**：使用属性判别器来优化模型，提高对指定属性的控制准确性。

4. **领域知识增强**：
   - 如果评论生成与特定领域相关，可能会使用基于主动学习的领域知识增强技术。这包括：
     - **指令微调数据主动学习与生成模块**：自动扩充和生成高质量的指令微调数据。
     - **领域知识问答数据自动构建模块**：将非结构化的领域知识结构化，并生成相关的问答数据。

5. **多模态内容生成**：
   - 对于需要结合图像等多模态信息的评论生成，可能会使用多模态思维链技术，这包括：
     - **多跳跨模态注意力模块**：在不同模态间进行信息交互和推理。
     - **对比学习模块**：学习不同推理路径的相似性和差异性。
     - **强化学习模块**：根据反馈信号优化推理过程。

6. **输出结果**：
   - 最终，大模型会根据上述技术和用户给出的指令，生成符合预期情感倾向、主题、长度和多样性的评论文本。

文本生成流程依赖于人工智能技术和算法，以及用户给出的具体指令来生成定制化的文本内容。

（from 李庆晓）
 问：敏感词是如何判定的，是有维护一个库来判定吗，如果有的话，库的数据来源是什么？
答：有敏感词库，合并的开源敏感词表

问：情感倾向、评论主体、文本设置这些通过prompt来和大模型交互，让大模型按预期处理输出结果
答：对

问：prompt示例
答：
阅读文章【{title} {content}】，发表一条评论。

阅读文章【{title} {content}】，发表一条【{senti}】情感的评论。

阅读文章【{title} {content}】，发表一条与【{entities}】有关的评论。

阅读文章【{title} {content}】，发表一条【{senti}】情感且与【{entities}】有关的评论。

阅读文章【{title} {content}】，发表一条对【{viewpoint}】持【{stance}】立场的评论。
