>双指针

1. 合并两个有序链表
2. 合并k个有序链表
3. 寻找单链表的倒数第k个结点
4. 寻找单链表的中点
5. 判断单链表是否包含环丙找出环起点
6. 判断两个单链表是否相交并找出交点



```js

// 6.判断两个单链表是否相交并找出交点
```

2. 合并k个有序链表
3. 寻找单链表的倒数第k个结点
	1. 快慢指针
	2. fast先走k 之后同步 slow m fast m-k 
4. 寻找单链表的中点
	1. 快慢指针
	2. slow k fast 2k fast为null时，slow为中点（偶数节点 返回中点为靠后的）
5. 判断单链表是否包含环并找出环起点
	1. 快慢指针
	2. 第一次slow k  fast 2k 第二次 slow k-m fast k-m 最后相遇点为环起点
6. 判断两个单链表是否相交并找出交点
	1. 双指针
	2. 链表相连 同步向前，相等即为交点
