setup & teardown


setup：beforeEach beforeAll
teardown：afterEach afterAll

执行顺序

beforeall afterall都只执行一次
beforeeach aftereach 会在每一个describe/test/it执行一次

在什么时候用

beforeall： 在最开始只执行一次（setup）
数据库连接和创建
创建临时文件

afterall：
数据库断开链接
临时文件 删除

beforeeach：
pinia store

aftereach：
reset


```js

/**

vitest独有

可以设置返回函数

执行顺序 
beforeAll beforeEach afterEach afterAll callback-afterAll

定义的afterall执行在callback-afterall之前

*/

beforeAll(()=>{
	// xxx
	return ()=>{
		// === afterAll
	}
})

beforeEach(()=>{
	// beforeEach
	return ()=>{
		// === afterEach
	}
})


```
